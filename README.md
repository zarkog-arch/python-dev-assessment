# Python Developer Assessment
This repository is for my developer assessment tasks


## Project Overview
This project served as an assessment to demonstrate foundational skills in Python programming, problem-solving, and essential development tools like Git and GitHub. The tasks covered setting up an environment, version control, code style, core data structures, OOP, error handling, and basic API interaction.

## Running the Code
To run the Python code in this repository:

1.  **Prerequisites:** Ensure Python 3.11+ is installed on your system.
2.  **Dependencies:** Install the necessary third-party libraries:
    ```bash
    pip install black flake8 requests
    ```
3.  **Execution:** Run any individual task file from the command line inside the project folder:
    ```bash
    python <filename>.py 
    # Example: python dsa_challenges.py
    ```
